# Voice Samples

Placeholder audio samples for testing voice cloning.

These are short audio files from the [pygame examples](https://www.pygame.org/) project,
licensed under the [LGPL](https://www.pygame.org/license).

## Usage

Select any of these files as a voice reference in the VoiceCast app to test
voice cloning with different audio sources.

## Adding Your Own Samples

Drop any `.wav`, `.mp3`, `.ogg`, or `.flac` file into this directory.
For best voice cloning results, use:
- **Duration**: 5–30 seconds
- **Quality**: Clear speech, minimal background noise
- **Format**: WAV or MP3 (44.1kHz or 48kHz recommended)
