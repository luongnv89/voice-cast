# Voice Samples

Voice samples for testing voice cloning in VoiceCast.

These samples were generated using macOS `say` command and are free to use.

## Samples

| File | Voice | Duration |
|------|-------|----------|
| `sample_female.wav` | Alice (female) | ~5s |
| `sample_male.wav` | Thomas (male) | ~6s |

## Usage

Select any of these files as a voice reference in the VoiceCast app to test
voice cloning with different voices.

## Adding Your Own Samples

Drop any `.wav`, `.mp3`, `.ogg`, or `.flac` file into this directory.
For best voice cloning results, use:
- **Duration**: 5–30 seconds
- **Quality**: Clear speech, minimal background noise
- **Format**: WAV or MP3 (24kHz or higher recommended)
- **Content**: Natural speech with varied intonation
